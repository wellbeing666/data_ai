# 销量下降分析方法

## 分析目标

销量下降分析的目标是找出可能相关的维度、时间段或指标变化，而不是证明确定因果。

分析结论应使用“可能”“显示”“相关”“可能有关”“需要进一步验证”等谨慎表述。

## 常用拆解路径

时间趋势分析：按日、周、月观察销量、销售额、订单数、客单价等指标变化。

区域拆解：比较不同区域、城市、门店的下降幅度，识别下降更明显的区域。

品类拆解：比较不同品类、商品、SKU 的销量变化，识别主要拖累项。

渠道拆解：比较线上、线下、平台、门店等渠道变化，判断下降是否集中在某一渠道。

客户拆解：比较新客、老客、会员、非会员等群体变化。

价格因素：如果有价格、折扣、促销字段，可观察价格变化与销量变化是否同步。

库存因素：如果有库存、缺货、补货字段，应检查销量下降是否与缺货或库存不足相关。

## 常用指标

销量、销售额、订单数、客单价、转化率、复购率、退货率、折扣率、库存量、缺货率都可以作为分析指标。

如果只有销量字段，结论只能围绕销量在不同时间和维度上的变化展开。

如果缺少日期字段，无法判断下降趋势发生的时间窗口。

如果缺少维度字段，只能做总体变化描述，难以定位可能原因。

## 解释规范

不能写“销量下降是由某因素导致”，应写“销量下降可能与某因素相关”。

相关性结论需要说明限制，例如样本范围、字段缺失、外部因素未纳入等。

建议优先输出可行动方向，如重点复盘下降明显的区域、品类、渠道或时间段。
