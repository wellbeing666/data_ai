# 报告与 PPT 表述规范

## 结论结构

报告结论应先给出总体发现，再说明关键维度差异，最后给出行动建议和限制说明。

PPT 大纲通常包括：分析目标、数据概览、关键发现、图表解读、建议动作、限制与下一步。

## 谨慎表达

对于销量下降、转化变化、客户流失等业务问题，应避免确定因果表述。

推荐使用“数据显示”“可能与”“呈现出”“相关”“建议进一步验证”等表达。

不推荐使用“证明”“导致”“根本原因一定是”等绝对表述。

## 成绩分析表达

成绩分析应重点突出班级差异、及格率、优秀率、低分段风险和样本量。

如果某班级平均分较高，可以写“该班级整体表现较好”；如果优秀率较高，可以写“高分段占比相对突出”。

如果及格率较低，应建议关注基础薄弱学生群体，但不要直接归因到教师或教学质量。

## 建议动作

建议应尽量可执行，例如复盘下降明显的区域、核查缺失字段、关注样本量较小的分组、补充日期或维度字段。

如果字段不足，应优先建议补充数据，而不是输出过度推断。
