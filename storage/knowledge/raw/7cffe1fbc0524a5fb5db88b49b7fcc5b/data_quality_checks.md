# 数据质量检查知识

## 缺失值

缺失值会影响统计结果的完整性。关键指标字段缺失时，应提示结果可能低估或偏差。

维度字段缺失会导致分组统计出现“未知”或空值分组，建议在分析前单独标记。

## 重复值

如果存在订单号、学生学号、客户 ID 等唯一标识字段，应检查重复记录。

重复记录可能导致人数、订单数、销量或销售额被重复计算。

## 异常值

数值字段应检查极端值，例如负销量、负销售额、超过合理范围的成绩。

成绩字段通常应在 0 到 100 或指定满分范围内。超出范围时需要在质量问题中说明。

销量、销售额等业务指标如果出现负值，需要判断是否代表退货、冲销或录入错误。

## 日期字段

日期字段应检查是否能正确解析，是否存在异常未来日期或过早日期。

做趋势分析时，日期字段是必要字段。没有日期字段时，不能可靠判断趋势变化。

## 样本量

样本量过小会降低结论稳定性。分组后某些组样本量很少时，应避免过度解读。

如果按班级、区域、品类等维度拆分后样本过少，应在限制说明中提示。
