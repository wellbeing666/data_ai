# 成绩分析业务口径

## 常用指标

平均分用于衡量班级或群体的整体成绩水平，通常按 `总分 / 人数` 计算。

最高分和最低分用于观察成绩区间，但不能单独代表整体教学效果。

及格率用于衡量达到基础要求的学生占比，常见口径为 `成绩 >= 60 的人数 / 总人数`。

优秀率用于衡量高分段学生占比，常见口径为 `成绩 >= 90 的人数 / 总人数`。

中位数可以辅助判断平均分是否被极端值拉高或拉低。

标准差用于衡量成绩离散程度。标准差越大，说明学生成绩差异越明显。

## 分组维度

成绩分析通常优先按班级、年级、科目、考试批次、任课教师等维度分组。

如果目标是“按班级统计”，优先输出班级维度下的平均分、及格率、优秀率、人数、最高分、最低分。

如果数据中同时存在班级和科目，应先判断用户目标是否关注单科表现还是综合表现。

## 解释规范

成绩分析应突出班级差异、及格率、优秀率和低分风险。

当发现某个班级平均分较低时，应表述为“该班级成绩表现相对较弱”或“需要进一步关注”，不要直接推断教学质量原因。

如果数据缺少学生姓名或学号，不影响班级聚合统计，但会限制个体层面的追踪分析。

如果数据缺少班级字段，则不能完成按班级统计，应在限制说明中指出。
