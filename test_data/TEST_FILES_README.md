# 测试文件说明

本目录提供两份面向演示的测试数据，分别覆盖“数据分析”和“情景预测”功能。

## 1. 数据分析测试文件

文件：

`analysis_grade_scores_test.xlsx`

推荐测试问题：

`把这批 Excel 成绩按班级统计并生成图表`

设计目的：

- 测试 Excel 上传和字段画像。
- 测试“班级、姓名、成绩”字段识别。
- 测试按班级统计人数、平均分、最高分、最低分、及格率、优秀率。
- 测试图表生成，例如班级平均分柱状图、及格率柱状图。
- 测试数据清洗能力：文件中包含一个空成绩、一个“缺考”非数字成绩、一个缺失单科成绩。

核心字段：

- 班级
- 姓名
- 学号
- 语文成绩
- 数学成绩
- 英语成绩
- 成绩
- 出勤率
- 作业完成率
- 备注

预期现象：

- 高一3班整体成绩较高。
- 高一4班整体成绩较低，及格率和平均分会相对靠后。
- 非数字成绩“缺考”应被清洗或在报告中提示。

## 2. 情景预测测试文件

文件：

`scenario_prediction_sales_budget_test.csv`

推荐测试问题：

`如果下个月营销预算增加 20%，哪些商品的销量最可能提升？`

设计目的：

- 测试 CSV 上传和字段画像。
- 测试情景假设解析：干预变量为“营销预算”，变化幅度为“增加 20%”。
- 测试预测目标识别：目标指标为“销量”。
- 测试对象维度识别：对象维度为“商品”。
- 测试预测结果排序：输出预测变化 Top 商品。
- 测试图表生成：预测变化排行、基线值与预测值对比。
- 测试鲁棒性：文件中包含一个缺失营销预算和一个低库存异常样本。

核心字段：

- 商品
- 日期
- 品类
- 地区
- 渠道
- 销量
- 营销预算
- 单价
- 折扣率
- 库存
- 评分

预期现象：

- 营销预算、折扣率、库存与销量存在可学习的正向关系。
- 预测结果应给出若干商品的销量变化估计。
- 结果应使用谨慎表述，不能把预测说成确定因果。

## 房价预测

**数据分析类问题**

- 哪些因素和房价关系最明显？
- 不同区域的平均房价、总价、中位数有什么差异？
- 面积、房龄、楼层、地铁距离分别如何影响房价？
- 哪些小区或区域的房价明显高于整体水平？
- 房价最高的前 10 个区域分别有什么共同特征？
- 不同户型的单价分布有什么差异？
- 房价是否存在异常值？哪些房源价格明显偏高或偏低？
- 房价随建筑面积变化的趋势是什么？
- 靠近地铁、学校、商圈的房源是否更贵？
- 不同年份建成的房子价格差异如何？

**情景预测类问题**

- 如果某套房面积增加 10 平方米，预测总价会变化多少？
- 如果距离地铁从 2 公里缩短到 500 米，房价可能提升多少？
- 如果房龄增加 5 年，预测价格会降低多少？
- 如果某区域新增地铁站，周边房价可能上涨多少？
- 如果装修等级从普通变为精装修，房价可能变化多少？
- 如果楼层从低层调整为中高层，预测价格会怎样变化？
- 如果同一套房从两居变为三居，价格可能变化多少？
- 如果贷款利率下降，哪些区域房价最可能受影响？
  这个问题需要数据里有利率、时间或成交周期等字段，否则只能做弱推断。
