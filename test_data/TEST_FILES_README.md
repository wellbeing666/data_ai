# 测试文件说明

本目录提供两份面向演示的测试数据，分别覆盖“数据分析”和“情景预测”功能。

## 1. 数据分析测试文件

文件：

`analysis_grade_scores_test.xlsx`

推荐测试问题：

`把这批 Excel 成绩按班级统计并生成图表`

设计目的：

- 测试 Excel 上传和字段画像。
- 测试“班级、姓名、成绩”字段识别。
- 测试按班级统计人数、平均分、最高分、最低分、及格率、优秀率。
- 测试图表生成，例如班级平均分柱状图、及格率柱状图。
- 测试数据清洗能力：文件中包含一个空成绩、一个“缺考”非数字成绩、一个缺失单科成绩。

核心字段：

- 班级
- 姓名
- 学号
- 语文成绩
- 数学成绩
- 英语成绩
- 成绩
- 出勤率
- 作业完成率
- 备注

预期现象：

- 高一3班整体成绩较高。
- 高一4班整体成绩较低，及格率和平均分会相对靠后。
- 非数字成绩“缺考”应被清洗或在报告中提示。

## 2. 情景预测测试文件

文件：

`scenario_prediction_sales_budget_test.csv`

推荐测试问题：

`如果下个月营销预算增加 20%，哪些商品的销量最可能提升？`

设计目的：

- 测试 CSV 上传和字段画像。
- 测试情景假设解析：干预变量为“营销预算”，变化幅度为“增加 20%”。
- 测试预测目标识别：目标指标为“销量”。
- 测试对象维度识别：对象维度为“商品”。
- 测试预测结果排序：输出预测变化 Top 商品。
- 测试图表生成：预测变化排行、基线值与预测值对比。
- 测试鲁棒性：文件中包含一个缺失营销预算和一个低库存异常样本。

核心字段：

- 商品
- 日期
- 品类
- 地区
- 渠道
- 销量
- 营销预算
- 单价
- 折扣率
- 库存
- 评分

预期现象：

- 营销预算、折扣率、库存与销量存在可学习的正向关系。
- 预测结果应给出若干商品的销量变化估计。
- 结果应使用谨慎表述，不能把预测说成确定因果。
