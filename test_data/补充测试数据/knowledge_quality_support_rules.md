# 制造质量与客服排班测试知识

## 制造质量口径

- 不良率 = 不良数 / 产量。
- 高风险组合建议按生产线、工序、班次三层维度交叉查看。
- 夜班、涂装、终检通常需要结合设备停机、环境湿度和来料等级做复核。
- 缺失的设备停机分钟或环境湿度不应直接填 0，应在报告限制中说明数据质量问题。

## 客服排班预测口径

- 平均响应时长越低越好。
- 工单量、夜间占比、复杂工单占比通常会推高响应时长。
- 客服人数增加可能降低响应时长，但预测结果只表示历史数据下的估计关系，不代表确定因果。
- 预测报告中建议使用“预计”“可能”“显示出变化”，避免使用“必然”“保证”“证明”。

## 食堂窗口预测口径

- 平均排队时间越低越好。
- 开放窗口数是绝对数量字段。“增加 2 个窗口”应按绝对增量处理，不应误解为增加 2%。
- 如果模型无法处理绝对增量，应在限制中说明，并给出保守解释。
